# Changelog (since the first combined draft)

1. **Bug fixed** in `agentsec_sim.py` and `agentsec_plus.py` (and the copies embedded in `notebooks/combined_study.ipynb`): the simulated
   model was given a fresh chance to obey an injection at every later decision point instead of exactly one. One line (`injected = False`).
   Effect: single-attempt guardrail attack rates fall (no defence, A2 ASR@1 74.7% -> 63.2%; prompt guardrail 39.6% -> 28.7%).
   Unchanged: all 25-attempt results, all compromised-model results, all monitor-only defences. All tables and figures regenerated; `test_equivalence.py` passes.
2. **Susceptibility measured** (Section 6.10, `empirical/`): the monotone logistic law is rejected (LRT p ~ 1e-9) on a 1.5B model; guardrail effect not detectable there; harness re-run with measured per-family rates and Beta posterior uncertainty.
3. **End-to-end real-model pilot** (Section 6.11, `pilot_real_v1/`): Qwen2.5-1.5B and 7B run through the same tasks, oracle and monitors. Corrected for (a) the model's own spontaneous errors (attacker-aligned counting) and (b) parse failures (lenient re-parse).
4. **Manuscript**: abstract, contributions, Sections 6.9-6.11, discussion, limitations and reproducibility rewritten; the cross-validation claim in 6.9 is downgraded to a consistency check (the two models share assumptions and disagree on guardrail persistence); erratum added.
5. **New notebook** `notebooks/realllm_agentsec_eval_v2.ipynb`: repeats the real-model evaluation with attacker-aligned metrics, a lenient parser, full raw logs, three scales and an optional API model.
6. **References verified** (12 entries checked against arXiv, NeurIPS, ACM/IEEE and DTIC pages; authors, titles, venues and identifiers completed; Wallace et al. 2024 added; related-work claims restated to match the sources).
7. Outstanding: larger real-model run; adaptive attackers against detectors; hand-labelling of the oracle sample.
8. **Ready for the real data**: the real-model passages of the paper (abstract, 6.11, discussion, limitation) are now generated from JSON (`pilot_section.py`); `pilot_real_v2/analyze_v2.py` converts a v2 results pack (with Holm correction and non-inferiority differences) and was tested end to end on a stand-in pack; `ANALYSIS_PLAN.md` pre-specifies endpoints and sample sizes; notebook gains stacked attack families (6-7) at `full` scale and larger benign samples (8 / 10 per task).

The results pack received on 2026-10-28 was the notebook's offline stand-in run (`stub: true`) and was **not** used.
10. **Oracle audit of the first pilot** (100 attack episodes hand-labelled by the author): agreement 93% (kappa 0.86) with the original rule; the rule counted a read of /secrets as obedience, which the author's goal-based labels did not, so it was tightened (reading a secret alone is no longer 'obedience'). With the tightened rule agreement is 97% (kappa 0.94); pilot obedience figures changed by 1-8 points (e.g. 7B no-defence 83% -> 81%, behind P3 86% -> 78%); executed-attack rates are unchanged except 7B no-defence 82% -> 79%. The labelling sheet truncated long arguments at 140 characters (hid a marker on one row); now 400. Remaining disagreements: one paraphrased falsification the exact-phrase oracle misses; two rows labelled 0 although the logged call contains the attacker's payload (worth re-checking). Labels stored in `pilot_real_v1/data/human_labels_pilot.csv`.
11. **First v2 real-model data (Qwen2.5-1.5B, 156 attack / 78 benign episodes per defence)** analysed with `pilot_real_v2/analyze_v2.py` and merged with the first pilot (7B stays from the first pilot until its v2 run arrives; `pilot_real_v2/runs/` holds one file per model, newest run wins). The pack predates the tightened alignment rule, so `fix_alignment` re-derives it from the logged calls (task 1: needs the mail to the attacker; task 8: also counts the unsafe value sent through another tool). Results replicate the first pilot: no-defence obedience 67% (pilot 63%), prompt guardrail 65%, spotlighting 47%, spotlight+detector 12%, P3 admits 1%, layered 0%.
12. **Full two-model v2 run incorporated** (`results_pack`: Qwen2.5-1.5B and 7B, medium scale, `stub: false`): Section 6.11 is now an 'evaluation' (156 attack / 78 benign episodes per defence and model) instead of a pilot; both models come from the v2 run (identical 1.5B data to the earlier partial file). New headline: the 7B model's detector stack stays at 0% obedience and 0% at ten attempts against static attacks, so the simulated '100% under persistence' claim is not supported for detector stacks; the prompt guardrail alone still reaches 83-85% after ten attempts. P3 admits 1.3% (1.5B) and 7.7% (7B; the falsified-report task). Non-inferiority (10 points): P3 and layered pass for 7B; layered fails for 1.5B. Section 6.1 now points to 6.11 for the erosion assumption.
